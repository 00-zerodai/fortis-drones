Understand the software

Open autopilot software, not an AI-in-a-box.

ArduPilot’s source code is published under the GNU GPLv3. It is software that runs on compatible flight-controller hardware; it is not itself a drone, an AI model, or a guarantee that a vehicle is safe or legally approved.

01 / OPEN SOURCE

Inspect and adapt

The project publishes its code and documentation openly. Read the license and hardware requirements before selecting components or commissioning a setup.

02 / CIVILIAN USE

Practical applications

Documented civilian examples include aerial photography, mapping, agricultural observation, inspection and research. Every operation still needs competent piloting and appropriate approvals.

03 / SETUP SUPPORT

Installation and home builds

Ask us about firmware installation, compatible-component checks and basic setup support for a lawful, non-weaponized, civilian home-built aircraft.

About AI: ArduPilot does not include a built-in AI model or task-specific dataset. Any separate AI tool or dataset must be independently sourced, tested and lawfully integrated; it is not part of this support offer and does not replace a qualified human operator.

Check RCAA requirements before every operation.

Drone operations in Rwanda must comply with current Rwanda Civil Aviation Authority (RCAA) rules and any required approvals. Operating without authorization or contrary to applicable regulations may lead to enforcement, including fines or imprisonment. Confirm current requirements directly with RCAA; this page is not legal advice or flight authorization.
